# AI-Powered Career Readiness & Job Matching Web Platform

## Project Description

This project is a web-based platform that helps students analyze their resumes, identify skill gaps, explore job opportunities, and improve their career readiness.

## Features

* Student Registration and Login
* Resume Upload and AI Resume Analysis
* Job Matching and Recommendations
* Skill Gap Analysis
* Career Readiness Score
* Personalized Learning Roadmap
* What-If Skill Simulator
* AI Interview Questions

## Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Web Server: IIS / PHP-supported hosting
